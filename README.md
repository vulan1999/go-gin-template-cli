# Go Gin Template Generate CLI

A CLI project to auto generate Gin API project using (bubbletea)[https://github.com/charmbracelet/bubbletea] for CLI UI and Golang itself for generate logic

## Folder structure generate from CLI
```text
project
├── cmd
│   └──  main.go # Entry point
├── config
│   └── enviroment.go # Reading enviroment variables
├── internal
│   ├── models # Define data model and dto
│   ├── handlers # Manage HTTP requests and responses
│   ├── repositories # Define Repository for all database operations
│   ├── services # API business logic
│   └── routes # Define api route
└── README.md # Project Description
└── go.mod # Dependency management file
└── go.sum # Dependency checksum file
```
